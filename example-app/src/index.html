Platform notes

  • iOS: Set up associated domains before readPassword(). On iOS 26.2 and later, a resolved promptDialog() only means the system accepted the request, not that the user saved the credential.
  • Android: Dismissing the save prompt rejects the promise. Saving uses the username, password, and optional URL from the form.
  • Web: Native autofill APIs are unavailable here. Expect errors for save and read calls.
